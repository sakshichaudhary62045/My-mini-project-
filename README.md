🌟 Mini JavaScript Projects:

This project is a collection of small JavaScript applications built on a single page using pure JavaScript (no frameworks).
It focuses on practicing DOM manipulation, events, and logic building.

🚀 Features:
😀 Even Odd Emoji Generator:
Enter a number in the input field
If the number is even → displays 🙂 emojis
If the number is odd → displays 😢 emojis
Number of emojis shown = entered value

🧮 Calculator:

A simple calculator that performs:
➕ Addition
➖ Subtraction
✖️ Multiplication
➗ Modulus

How it works:

Enter two numbers
Click any operation button
Result will be displayed instantly
🔢 Array Processor

Perform operations on a list of numbers.

Input format:

1,2,3,4

Features:

➕ Calculate Sum using reduce()
🔝 Find Maximum value using Math.max()
⚖️ Filter Even numbers using filter()

HTML (basic structure)
JavaScript (core logic)

🎯 Purpose

This project is built to:

Practice JavaScript fundamentals
Understand user input handling
Improve problem-solving skills
Build multiple mini apps in one file
📌 How to Run
Create an index.html file
Paste your JavaScript code inside a <script> tag
Open the file in your browser
Start using the apps 🎉
